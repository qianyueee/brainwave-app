## 1. 产品概述

**NeuroSync（ニューロシンク）** — 副标题「〜 音波×光波×脳波シンクロ誘導 ＆ 脳コンディション管理 〜」

- **做什么**：通过 Web Audio API 实时合成个性化双耳节拍（Binaural Beats）诱导脑波状态；配合脑波测定（EEG 头环/演示数据）做"脑状态"记录、分析与比较。两大价值：**听**（调谐）与**测**（管理）。
- **目标用户**：50-60 岁日本人。由此产生的硬性可用性约束见 §2.4。
- **平台**：移动优先的 Web App（内容列宽 480px 居中）；桌面端为左侧 240px 侧栏 + 最大 1024px 内容区两栏布局。
- **技术底座**（限制设计可行域）：Next.js 16 静态导出（无服务端渲染动态能力）、Web Audio 纯前端实时合成、Supabase 做账号/云端数据、Zustand 状态。**音频必须由用户手势启动**（iOS 限制）——任何"进页面即出声"的设计都不可行。

### 节目（Program）体系

| 类别 | 数量 | 说明 |
|---|---|---|
| 三大基础程序（Sync Sound） | 3 | リセット＆ディープ（174Hz/7.83Hz/15分）、クラリティ・フォーカス（432Hz/40Hz/20分）、ナイトリカバリー（136.1Hz/1.5Hz/30分）。各有专属音乐床垫 |
| 星座节目 | 12+110 | 12 星座固有节目 + 星座×9 差频模块（工厂生成）；96 首星座音乐床垫；每日推荐由天体计算生成（載波=自星座、差频=当日矩阵） |
| 配信プログラム | 动态 | 管理员制作、按用户组分发的合成器节目（云端拉取） |
| カスタムプログラム | 动态 | 管理员本地保存的合成器节目 |

所有节目播放时：诱导音（双耳节拍）由引擎实时合成，音乐床垫（若有）循环铺底，可再叠加自然音（雨/海/森/川 或用户上传音频），三路音量独立。

## 2. 全局体系（设计前必读）

### 2.1 导航结构

**底部导航（移动）/ 侧栏（桌面）5 项**（`components/nav-tabs.ts`，单一来源）：

| 路由 | 移动标签 | 桌面标签 | 图标 (lucide) |
|---|---|---|---|
| `/` | ホーム | Home / ホーム | Home |
| `/session` | セッション | Sync Session / シンク・セッション | Music2 |
| `/brain` | ブレイン | Sync Brain / シンク・ブレイン | BrainCircuit |
| `/report` | レポート | Sync Report / シンク・レポート | ChartColumn |
| `/history` | ヒストリー | Sync History / シンク・ヒストリー | History |

**菜单外页面**：`/settings`（仅首页右上角齿轮进入）、`/player`（仅节目卡/mini-player 进入，无返回钮，靠导航离开）、`/synth`（管理员，从 /session 进入）、`/admin`(管理员，从 /settings 进入)。

**已知结构特征**：页面 h1 是英文（Sync Session）+ 日文小字副标题，而底部导航是片假名（セッション）——两处命名不完全一致（见 §6 债务）。

### 2.2 四时主题（不是固定深色！）

`lib/theme.ts` 按时段切换 4 套调色板，边界 60s 渐变（`prefers-reduced-motion` 时瞬切）：

| 时段 | id | 底色 navy | 性格 |
|---|---|---|---|
| 00-06 | midnight | `#1E1B4B` 深靛 | 唯一深色主题 |
| 06-12 | day | `#f5e8c0` 奶油 | 浅色 |
| 12-18 | afternoon | `#c0e8d4` 薄荷 | 浅色 |
| 18-24 | evening | `#dcc8f0` 淡紫 | 浅色 |

- 全部颜色经 `--dyn-*` CSS 变量下发，Tailwind utility 形如 `bg-surface` / `text-text-secondary`。**Token 清单**：navy / navy-light / navy-lighter / primary / primary-dark / accent / accent-dark / surface / surface-border / text-primary / text-secondary / text-muted / **on-primary / on-accent / success / warning / danger**（后五个逐调色板按 ≥4.5:1 对比度调过——midnight 的 CTA 是深字浅紫底，浅色主题是白字深底）。
- 阴影体系随背景亮度自适应（neumorphism 双向阴影，`--shadow-neu-dark/light` 三档）。
- `data-color-scheme="light|dark"` 挂在 html 上；SVG 属性吃不了 var()，图表按此选实色组（`getBandColors(scheme)` / `compareSeriesColors(n, scheme)`）。
- **两块刻意固定深色的"艺术面"**：首页星座卡的星空条带（NIGHT_SKY 渐变）与 /session 的水曼陀罗卡（DEEP_WATER 渐变），四时主题下恒为深色，其上白字是有意为之。全屏可视化遮罩同理（`#04060d`）。
- 开发者后门：任意页面左上角 3 秒内连点 5 次 = 强制轮切 4 套主题（测试用，红点指示）。

### 2.3 字号・字体

- Tailwind 字号已整体重映射（globals.css @theme）：`text-xs`=14px / `text-sm`=16px / `text--base`=18px / `text-lg`=20px / `text-xl`=22px / 2xl+=原值。body 基准 18px。
- 字体：Noto Sans JP（构建期自托管）→ 系统日文字体兜底。
- Recharts 图表刻度为硬编码像素（12-16px 区间）。

### 2.4 无障碍硬约束（50-60 岁用户）

- 触控目标 **≥48×48px**（图标钮 w-12、行钮 min-h-12、滑块 22px 圆钮+细轨道为用户钦定外观，是唯一例外）。
- 信息性文字 **≥14px**，正文 18px；对比度 ≥4.5:1（走 §2.2 的 token 即自动满足）。
- **缩放不可禁用**（viewport 无 maximumScale/userScalable）；正文可长按选择复制，仅控件禁选。
- `prefers-reduced-motion`：大部分常驻动画（breathe/星空/曼陀罗涟漪）会静止；页面渐入等仍在。

### 2.5 组件惯例

- **卡片三层**：页卡 `bg-surface rounded-3xl p-4 neu-raised`（浮起）；对话框 `p-6 neu-raised-lg`；嵌入面板 `rounded-2xl bg-navy neu-inset`（凹陷）。整体为 Soft UI / Neumorphism 风格。
- **主按钮** `h-12 rounded-2xl bg-primary text-on-primary font-bold`；次级 `bg-navy text-text-secondary neu-raised-sm`；危险操作 `text-danger`。**没有统一的 Button 组件**——约 40 种按钮写法散落各处（见 §6）。
- **SelectDropdown**（`components/SelectDropdown.tsx`）：56px 收起钮 + 内联展开 52px 选项列表（非弹层），単选打勾；用于測定者/測定データ二段下拉。
- **RangeSlider**：6px 细轨道渐变填充 + 22px 圆钮（用户钦定的原版外观）。
- **MiniPlayer**（全局播放条）：移动端浮于底部导航上方（fixed bottom-16，480px 内）；桌面端为内容区底部通栏（侧栏右侧起、贴底）。**只要有声音在响或暂停中就存在**：节目播放（显示节目名+残り時間+暂停/恢复钮，点击去 /player，在 /player 隐藏）；合成器试听/timeline 预览（显示「カスタム合成/タイムライン プレビュー」，点击去 /synth，在 /synth 隐藏）。条可见时页面底部自动加 padding。
- **常驻动画现状**：33 处卡片 breathe 脉动（3.5s 缩放 1.045）、星空闪烁、曼陀罗多层旋转涟漪、播放键呼吸——首屏几乎所有卡片都在动（设计再定夺，见 §6）。

### 2.6 播放模型（对 UX 最关键的一块）

用户已多轮打磨钦定的行为，设计时**不可改变语义**：

1. **点节目卡 = 选择**：设置选中节目+默认时长，进入 `/player`，**不自动播放**。
2. **播放页按「再生」**才出声（手势内启动，满足 iOS）。
3. **播放中离开播放页** → mini-player 出现（全局可暂停/恢复/点回）。
4. **再点正在播放的节目卡** → 只进播放页，进度/定时不重置（"播放中保护"，暂停中同样生效；判定用音频真源 playingProgramId）。
5. **别的节目在响时点新卡** → 停掉在响的（不记日志）、选中新节目，播放页显示"刚点的那个"（空闲待播放）。
6. **真暂停**：`ctx.suspend()` 冻结一切（进度/频率渐变/自然音/音乐），恢复原位续播；锁屏控件同步 play/pause。
7. 选中节目/定时/三路音量**持久化**（刷新不丢）；播放运行态不持久化（刷新后音频停，页面仍显示原节目）。
8. 默认音量：ビート 20%・ミュージック 60%・自然音 50%。

### 3.1 `/` — Home（ホーム）

**用途**：每日入口——今日推荐频率（星座驱动）+ 脑状态一览。

| # | 分区（自上而下） | 内容与交互 |

### 3.8 `/synth` — 合成器编辑页（管理员）

未登录/无权限各有整页拦截文案。功能极重：顶部返回箭头+「カスタム合成器/タイムライン」→ timeline 分段条（增删段/命名/时长）→ 模式选择（自由/纯音/binaural/isochronic ×单声道/立体声）→ 基频输入 → 播放/停止 → 颤音面板 → 立体声监听（左/右/双）→ 声道 tab → 逐层振荡器卡列表（频率/音量/音色/颤音，最多 8 层）→ 导出 → 保存预设 → 预设导入导出 → 存为节目。此页小字与小触控目标最多（§6）。

### 3.9 `/admin` — 管理面板（管理员）

返回箭头 + 页内 3 tab：ユーザー（搜索/角色变更/组分配）/ グループ（增删改组）/ プログラム（把配信节目指派给组）。非管理员自动跳回首页。

### 3.10 旧路由跳转桩

`/mind → /session`、`/profile → /brain`、`/log → /history`、`/compare → /report`（客户端 redirect，闪一下「移動しています…」）。

## 4. 核心用户流

1. **每日听音频（最短路）**：打开 App → 首屏推荐 CTA（1 滚动内）→ /player → 按再生 → （可选）调音乐/自然音混音 → 听完自动结束记日志；中途导航离开由 mini-player 兜底。
2. **测定**：/brain → 选測定者 → 測定を開始 →（对着 demo 或头环）→ 終了 → 弹窗取り込む → /report 看雷达与频段。
3. **比较**：/report 底部勾 2-3 条测定 → 雷达/频谱叠加对比。
4. **回看**：/history 日历+下拉选记录 → 推移图 →「レポートで見る」去报告页只读查看该次。
5. **管理员制作节目**：/session → 新規作成/タイムライン → /synth 编辑 → 存为节目 → /session 卡上公開 → /admin 指派给组 → 组内用户在 /session 见到配信节目。

## 5. 数据与状态要点（影响 UI 的）

- **持久化**（普通 localStorage，未登录也生效）：选中节目 id、定时时长、三路音量、自然音选择、マイ星座。**不持久化**：播放运行态、会话统计（→§6）。云端（登录后）：测定记录、脑特性、自定义音频、合成器预设/节目。
- **同一数据多处出现**（改设计时保持一致性）：3 指标瓷砖（首页+/report）、6 指标雷达（首页小/report 大/history 小/比较叠加）、8 频段（/brain 条形 vs /report 饼图，同一配色）、测定记录列表（/brain 原始录制 vs /history 已导入——两套数据源，见 §6）。
- **权限分层**：未登录（可听可测不可存）→ 登录（云端记录、配信节目按组）→ 管理员（synth/admin/自定义节目/全部配信可见）。
- **配信节目列表是内存态**，进入 /session 或 /player 需要时拉取，有「読み込み中…」态。

## 6. 已知 UX 债务（设计时可一并解决的现存问题）

1. **「レポートで見る」同名双语义**：/history 版=只读查看（有返回横幅）；/brain 版=导入并改写"最新记录"（连首页指标都会变，无提示无退路）。
2. **"最新"排序 bug**：导入旧测定后，全 App 的"最新"指向它（取数组末尾而非最新日期），推移图 X 轴可能倒序。
3. **会话统计不持久化**：/history 的セッション次数/合計分钟重开永远归零，日历 accent 点随之消失。
4. **两套一模一样的记录列表**：/brain 過去の測定（原始）与 /history 脳波の記録（已导入）UI 完全相同、数据源不同、删除互不同步，页面无区分说明。
5. **三语混杂**：页面 h1 英文 / 底部导航片假名 / 星座推荐节目名是机器拼接英文（如「639Hz × 6Hz Emotion & Inner Calm」）——对 50-60 岁日本用户负担大，节目名日文化未做。
6. **常驻动画偏多**：33 处 breathe + 星空 + 曼陀罗同时动；WebGL 可视化空闲时也满帧渲染且不理会 reduced-motion。
7. **浅色主题下播放页曼陀罗发绿**：着色器减色渲染在浅底上产生紫的补色（绿），观感突兀（机制"正确"，配色策略问题）。
8. **/synth 与 /admin 未跟上无障碍达标**：仍有小字（text-xs 密集）与 <48px 控件，且 /synth 单页承载功能过重。
9. **auth 门槛三种做法**：/report 整页锁、/history 半页锁、/brain 不锁——不统一。
10. 测定质量/指标术语（総合、ゾーン率、信号质量）在多数出现处**无解释**（仅 /report 雷达卡有「?」帮助）。
